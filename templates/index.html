1. Google Таблица — чтение и запись

Ссылка запоминается после успешной загрузки. При следующем открытии BOT Point таблица загрузится автоматически. Для изменения вставь другую ссылку и нажми кнопку ниже.

ID сборки пока используется только для проверки заполнения отчётов и не участвует в поиске, усреднении или записи в Google. Выбор столбца ID сохраняется для будущих версий.

Если Telegram больше Google более чем на 2 поинта — требуется одобрение в «Проверке сообщений», запись блокируется. Остальные отличия усредняются с округлением вверх. Партномера, которых нет в Google, автоматически добавляем в конец результата. Существующий порядок и внутренние пустые строки сохраняются.

Период и режим расчёта применяются к сравнению и ручной проверке.

Автообновление выключено. После включения новые проверенные отчёты будут записываться в Google без подтверждения.

Проверь столбцы и первую строку перед включением автоматической записи. Отчёты с расхождениями попадут на ручную проверку.

Перед записью приложение проверяет текущие значения непосредственно в Google. Повторные нажатия не пересчитывают те же сообщения второй раз.

2. Telegram — контроль ID сборки

Отдельная настройка уведомлений: включается вручную, сохраняется после обновлений и распространяется только на новые отчёты. Учёт по ID сборки в Google Таблице пока не используется.

Предупреждения в Telegram выключены. При включении BOT Point будет отвечать в той же теме на новые отчёты без ID сборки.

Технические сведения

Проверяем параметры подключения…

История из Telegram загружается в локальную базу. Запись поинтов в Google Таблицу управляется отдельно. ID сборки пока не участвует в расчёте.

Если Telegram не авторизован, подключи аккаунт через Bot Manager или login_telegram.bat.

Проверка сообщений

Сюда также попадают случаи увеличения поинтов более чем на 2 относительно Google. До одобрения такие значения не записываются. По каждому сообщению складываются числа в конце строк (кроме строки партномера и итоговой строки). При расхождении сообщение не влияет на автоматическую запись. Проверь рассчитанные поинты, при необходимости исправь число и нажми «Одобрить» — отчёт будет сразу отправлен в Google.
