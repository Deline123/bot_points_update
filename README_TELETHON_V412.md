# BOT Point v4.1.2
Диагностика POST /api/telethon-diagnostics проверяет настройки, формат сессии, подключение, пользовательскую авторизацию, группу, тему и пробное чтение. Не записывает отчёты или Google Sheets. Ошибки передаются только как контролируемые коды и фиксированные сообщения. Синхронизация также использует эту диагностику. Поддержаны namespaces channels и messages для методов форумных тем. Ручная синхронизация в облаке возвращает 202 и выполняется в фоне (Gunicorn больше не ждёт до 240 секунд); состояние обновляется в UI каждые 15 секунд. При остановке Render незавершённый импорт будет повторён по обычному расписанию. Ни ключи, ни тариф, ни настройки записи не изменены.
